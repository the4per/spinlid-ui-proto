# SpinLid — UI-прототипы: 6 дизайн-систем

Автономные HTML-прототипы трёх ключевых страниц SpinLid в шести разных дизайн-системах.
Без сборки, без зависимостей, без API — всё демо-данные. Открыл `index.html` — и работаешь.

## Как запустить (30 секунд)

**Вариант 1 — просто открыть.**
Откройте `index.html` двойным кликом. Дальше переходите по ссылкам на карточках.
Интернет нужен только для шрифтов Google Fonts — без сети страницы не ломаются, просто переключаются на системные шрифты.

**Вариант 2 — как сайт (рекомендую).**

```bash
git clone <адрес этого репозитория>
cd <папка>
python -m http.server 8090
# открыть http://localhost:8090
```

На Windows вместо python можно использовать что угодно, раздающее статику:
`npx serve .` или расширение Live Server в VS Code.

## Что внутри

| Папка / файлы | Система | Характер |
|---|---|---|
| `01-*.html`, `02-*.html`, `03-*.html` (в корне) | **Bento** | тёплый крем/персик, сетка-бенто — эталон |
| `designs/shadcn/` | **Shadcn** | нейтральный цинк, data-таблица, ближе всех к текущему стеку |
| `designs/neobrutalism/` | **Neobrutalism** | рамки 2px, жёсткие тени, жёлтый+фиолетовый |
| `designs/editorial/` | **Editorial** | газетная вёрстка, серифы, цитаты-выносы |
| `designs/enterprise/` | **Enterprise** | тёмный дашборд (Vercel/Heroku-стиль) |
| `designs/premium/` | **Premium** | Apple-полировка: белый, один синий акцент, пилюли |
| `index.html` | — | сравнение всех шести с превью |
| `preview/` | — | PNG-скриншоты каждой системы |

В каждой системе одни и те же три страницы:

1. **Вход поиска** — ниша + город + источники, быстрый старт, тонкая настройка
2. **Результаты** — фильтры (все 20+ из текущего продакшена), сценарии, bulk-действия, экспорт/КП/ЛПР
3. **Поиск по боли** — ранжированные боли с барами частот, города/ниши, выдача с цитатами

## На что смотреть при выборе

- Откройте **страницу «Результаты»** в каждой системе — это самая плотная страница и честный тест.
- Взаимодействуйте: фильтры-чипы, сценарии, чекбоксы (появляется плавающая панель действий), «показать ещё» в болях — всё кликабельно.
- Дизайн-токены каждой системы — в CSS-переменных в начале файла (`:root`). Перенос в Next.js — прямая замена токенов.

## Происхождение систем

Пять систем — точная реализация открытых дизайн-скиллов [TypeUI / awesome-design-skills](https://github.com/bergside/awesome-design-skills) (MIT): shadcn, neobrutalism, editorial, enterprise, premium + bento. Палитры и типографика взяты из спецификаций скиллов без изменений.

---
*Прототипы не подключены к API SpinLid; все компании, отзывы и счётчики — демо-данные. Основной репозиторий проекта эти файлы не затрагивают.*
